# Thiệp Mời Lễ Tốt Nghiệp Online

Web tool tạo thiệp mời tốt nghiệp cá nhân hóa theo tên người nhận (`?to=Tên_Khách`).

## Cách tùy chỉnh

- Sửa thông tin trường, thời gian, địa điểm và hướng dẫn gửi xe trong file `js/config.js`.
- Mở `index.html` trên web để nhập tên khách mời và lấy link chia s

# Thẻ Tốt Nghiệp

Repository chứa mã nguồn trang web thiệp tốt nghiệp.

- Thay đổi cấu hình trong `js/config.js`.
- Thêm CSS trong `css/style.css`.
- Logic JavaScript trong `js/app.js`.
