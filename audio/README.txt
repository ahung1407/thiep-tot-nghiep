THƯ MỤC CHỨA NHẠC NỀN CHO THIỆP TỐT NGHIỆP
=========================================

Để thêm bài hát của riêng bạn:
1. Chép file nhạc định dạng .mp3 vào thư mục này (ví dụ: `audio/nhac-tot-nghiep.mp3`)
2. Trong công cụ tạo thiệp (tab "🎵 Âm nhạc"), điền đường dẫn: `audio/nhac-tot-nghiep.mp3`
3. Khi đưa web lên GitHub Pages / Vercel / Netlify, file nhạc trong thư mục này sẽ tự động phát khi khách bấm "Mở Thiệp"!
